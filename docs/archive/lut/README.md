# Tài liệu cửa hàng LUT (DownBeat) cũ

Lưu trữ sau lát `go-lut` (18/11/2026), chỉ để tham khảo cách viết. Cửa hàng hiện tại là cửa hàng giày; kế hoạch ở [plan/thiet-ke-giay.md](../../../plan/thiet-ke-giay.md).
Các liên kết tương đối bên trong các file này có thể không còn đúng.

- `tai-lieu-thiet-ke.md` / `.docx`: thiết kế CSDL, API, thuật toán gợi ý.
- `thiet-ke-tong-quat.md`: thiết kế tổng quát và lộ trình lát LUT.
- `ke-hoach-tong.md`: bảng giai đoạn → lát của cửa hàng LUT.
- `huong-dan-su-dung.docx`: hướng dẫn sử dụng bản LUT.
